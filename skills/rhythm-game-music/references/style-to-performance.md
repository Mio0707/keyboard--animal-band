# 从流派到可演奏资产

用于同一歌曲的多风格改编和分轨互动。沿用目标流派资料及实际音色选择；不要再建立一套提示词流程。

## 最小交付契约

一份实施卡记录：目标路线、资料实际读取方式、主律动的拍内起音、声部职责、旋律识别句与改写、和声配置、实际bank/program与鼓键、段落结构。可直接写入渲染清单的design与renderSelection，避免另抄多份文档。

将可确定的错误交给代码：音符时间和通道、音色真实存在、鼓键范围、分轨帧数/起点、实际WAV削波、MIDI与动作事件的来源哈希。不要把律动识别、张力解决、好听与否转成机械合格阈值。

先导出完整乐句的四种组合；同一正式混音增益下听鼓贝、旋律和声、旋律节奏组与合奏。不能听辨时写明待试听，继续完成已授权的候选，不声称风格验证通过。小样裁剪应在乐句边界；两版A/B只对试听副本匹配响度。

## 互动段落

具体路线与教材边界见[分流派段落推进](section-energy.md)。小样应覆盖主题到过渡再到新段的接口，而非始终只导出主题。

主题提供稳定可循环的语句；蓄力用该流派的织体、音区、动态和留白推进；高潮用乐队回应和层次展开。不要求Bossa、爵士也使用电子军鼓滚奏或锯齿低音。和声、低音与领奏一起规划段落接口。

四条交互轨是职责分组，鼓轨可包含轻打击乐，和声轨可包含吉他拇指与上层和弦；乐器名与画面角色分开。动作事件从实际渲染MIDI导出，静音或零音量回到静止。

多风格共页时保留既有按键语义；先确定切换时序、队列和录音行为，再选速度。相同BPM/拍号可保留整小节录音，不能保证录音的调性、内部节奏或风格自动适配。不同速度需要明确重录或实际时间伸缩支持。

## 本次可复现案例

换歌与独立演奏包使用[歌曲输入到演奏](song-input-performance.md)及`scripts/song_bundle.py`。下面的旧渲染器仅用于重现《茉莉花》，不能作为其他歌曲的默认生成器。

《茉莉花》最终候选由项目render_styles.py生成：jazz-funk与bossa-nova均使用--sound-plan；--pilot输出8小节及组合试听，再生成全曲。电子既有音频保持不变。共同96 BPM、4/4是该互动产品的选择，不是流派定义。

爵士放克的两小节鼓贝起音和comping为本项目综合设计，并非抄录教材鼓谱。Berklee/Larry Finn原作者公开教学强调先建立无加花的稳定鼓型、整支节奏组决定风格和较紧较轻的踩镲；教学文字已核对，未宣称听过音频或读取未取得的SVG谱图。依据：https://online.berklee.edu/takenote/basic-funk-for-drums/ 。
