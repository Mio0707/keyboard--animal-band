# Phonk / Drift Phonk

先选路线：经典Phonk偏Memphis/Hip-hop采样与暗色氛围；Drift Phonk可突出可调音高的808牛铃、失真低音和机械鼓机律动。二者不等于爵士放克，也不要把所有Phonk都写成四拍底鼓或同一个BPM。

## 实际参考与范围

[Native Instruments原作者制作教程](https://blog.native-instruments.com/phonk-music/)包含鼓、暗色低音、对位旋律、降采样及编排流程；[Soundtrap原作者Drift制作教程](https://blog.soundtrap.com/how-to-produce-drift-phonk/)介绍牛铃、鼓机、少量氛围层及饱和。均为厂商制作教学，不冒称学术教材；不同教程速度区间不同，不把其中一个数字当流派定义。未声称听过页面音频。

## 从谱面到本地音色

- 本机MuseScore General的bank128/program25 TR-808，note56实际映射到`TR-808 / 808 Cowbell`。它是**一个非键盘追踪的打击乐键**。要奏旋律，需要渲染该单音，再按参考音高移调/重采样；不能直接把旋律MIDI的60/62/64发送到鼓通道，那会换成其他打击乐。
- 在sound-plan中标明`renderEngine: pitched-drum-sample`、源鼓键、参考音高，以及独立的谱面通道。参考音高需分析源样本并记录方法；牛铃非谐波较多，分析结果是移调锚点，不等于音色真实度或人工听辨通过。
- 音色候选：TR-808鼓组、稀疏Warm Pad、Synth Bass 1＋明确的失真/音长处理、上述808 Cowbell旋律。`Synth Bass 1`不是自动获得的真实808滑音贝斯；有滑音必须实际实现，不能只写在标题。
- 自行重演民歌动机，不依赖外部说唱录音。主旋律可选片段成hook，或做有意的调式变体，但要同时改低音与和弦，不能只把旋律改小调后仍放原大调伴奏。
- 饱和是局部音色处理。避免长pad、密集牛铃和低音尾巴互相遮蔽；低频给底鼓起音留空间。失真后仍检查最终PCM削波，不能把数值溢出称为风格。

## 段落与互动

主题先建立短hook与稳定律动。Build可抽掉低频、把牛铃motif缩成呼应并渐进鼓组；Drop恢复牛铃与低音，写4＋4等乐句发展、休止和回答，不能全曲只复制两小节。当前键盘演奏默认4小节Build、4小节Drop，按次追加；完整主题长度由歌曲决定，不是流派通则。

同页96 BPM是本项目录音兼容选择，不宣称是Drift唯一速度。测试主题→Build→Drop、重复触发与回主题；动作事件必须来自实际谱面MIDI。牛铃轨的MIDI是旋律事件载体，实际音频由源打击样本移调渲染，清单应明确说明，不能把无Program Change的谱面MIDI当作自包含音色文件。
